# VaultX

**Cybersecurity**

A highly interactive cybersecurity command center dashboard simulating live threat monitoring.

## Features
- Fully responsive, production-ready React UI
- Interactive Framer Motion animations
- Tailwind CSS v4 styling
- Accessible layouts and robust error handling

## Tech Stack
- **Framework**: React 19 / Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Environment Variables
*(No API keys or secrets are required for this frontend prototype)*

## Deployment
This project is configured as a standard Vite SPA. It can be deployed out-of-the-box to Vercel, Netlify, or GitHub Pages.

## Known Limitations
- This is a frontend prototype; interactive data is simulated and not connected to a live backend database.
